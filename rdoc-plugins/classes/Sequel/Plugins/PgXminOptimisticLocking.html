module Sequel::Plugins::PgXminOptimisticLocking

  1. lib/sequel/plugins/pg_xmin_optimistic_locking.rb

By default, the plugin allows using the xmin= setter method to either increase or decrease the lock value. To prevent increases, which could potentially be used to skip an update when it update should be made, you can use the :prevent_increase plugin argument:

plugin :pg_xmin_optimistic_locking, prevent_increase: true

This plugin may not work with the class_table_inheritance plugin.

This plugin relies on the instance_filters plugin.
