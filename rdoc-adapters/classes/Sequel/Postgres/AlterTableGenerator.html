alter_constraint(name, opts=OPTS)

Alter an existing constraint. Options:

:deferrable

Modify deferrable setting for constraint (PostgreSQL 9.4+):

true

DEFERRABLE INITIALLY DEFERRED

false

NOT DEFERRABLE

:immediate

DEFERRABLE INITIALLY IMMEDIATE

:enforced

Set true to use ENFORCED, or false to use NOT ENFORCED (PostgreSQL 18+)

:inherit

Set true to use INHERIT, or false to use NO INHERIT (PostgreSQL 18+)

attach_partition(name, &block)

Attach an existing table as a partition of the altered table. This is preferable to using create_table with :partition_of for a number of reasons. Accepts the same block that you would pass to create_table with the :partition_of option.

detach_partition(name, concurrently: false, finalize: false)

Detach a partition from a partitioned table. The detached partition becomes a separate table. Arguments: name: Name of partitioned table concurrently: Use CONCURRENTLY when detaching, which reduces the locking required. finalize: Use FINALIZE when detaching, to complete a case where CONCURRENTLY was

used but could not complete the detach.
